# Mario Golf 64 Archipelago Setup Guide

## Requirements

- [BizHawk](https://tasvideos.org/BizHawk) 2.9.1 or later
- A Mario Golf 64 ROM (USA)
- The Mario Golf 64 Archipelago Lua script (`Mario_Golf_64_AP.lua`)

## Setup

1. Open BizHawk and load your Mario Golf 64 ROM.
2. Go to **Tools → Lua Console**.
3. Open `Mario_Golf_64_AP.lua` in the Lua Console and click **Script → Run**.
4. Connect to your Archipelago server using the AP client with your slot name and server address.

## Generating a Game

1. Create your YAML options file using the template provided by the Archipelago Launcher.
2. Upload it to the Archipelago website or use the Archipelago Launcher to generate locally.
3. Host or join a multiworld session.
