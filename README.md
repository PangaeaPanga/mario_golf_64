# Mario Golf 64 Archipelago Randomizer

This is the AP World for Mario Golf 64 to be used with [Archipelago](https://archipelago.gg/). It is in a playable, **alpha** state. Please report any issues in the Mario Golf 64 thread in the Archipelago Discord's future game design forum.

## Setup
View the setup guide [here](docs/setup_en.md).

## Quick Notes
- Make sure to delete your save file or erase your data in-game before starting a new game
- Check the YAML to see which options are not yet implemented
